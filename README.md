# 👑 سامانه کارت به کارت سلطنتی | Royal Pay VIP

یک پلتفرم وب بسیار لوکس، شیک و تشریفاتی برای شبیه‌سازی و انجام انتقال وجه کارت به کارت شتابی، صدور فاکتور و رسید رسمی با کیفیت بالا، مدیریت حساب‌ها و پنل مدیریت VIP.

---

## ✨ امکانات و قابلیت‌های کلیدی

1. **💳 کارت بانکی ۳ بعدی و واقع‌گرایانه (3D Interactive Card)**:
   - افکت چرخش ۳ بعدی با حرکت موس (Parallax Tilt) و چرخش پشت و رو (Flip).
   - چیپ متالیک طلایی EMV، نماد پرداخت بدون تماس NFC، نوار مغناطیسی و هولوگرام رنگین‌کمانی.
   - تشخیص هوشمند کلیه بانک‌های ایران (ملی، ملت، صادرات، تجارت، سامان، بلوبانک، پاسارگاد، سپه، شهر، رسالت و...).

2. **⚡ شبیه‌ساز پرداخت و رمز پویا (OTP Simulator)**:
   - تایمر معکوس ۱۲۰ ثانیه‌ای رمز یکبار مصرف.
   - نوتیفیکیشن پیامک بانکی شبیه‌سازی شده با دکمه کپی و درج خودکار.
   - محاسبه خودکار کارمزد شتابی طبق مصوبه رسمی بانک مرکزی.
   - تبدیل خودکار مبالغ به حروف فارسی در لحظه (مثلاً: یک میلیون تومان تمام).

3. **🧾 صدور رسید رسمی و دانلود تصویر (Digital Luxury Receipt)**:
   - موتور گرافیکی داخلی روی HTML5 Canvas با خروجی فوق‌العاده باکیفیت PNG (رتینا).
   - مهر طلایی برجسته شاپرک، شماره پیگیری، شماره ارجاع (RRN) و ریز تراکنش.
   - امکان دانلود تصویر، چاپ مستقیم (Print) یا اشتراک‌گذاری متن رسید.

4. **🔐 پنل مدیریت اختصاصی و VIP (Admin Dashboard)**:
   - ورود امن با پین کد مدیریت (پیش‌فرض: `1234`).
   - داشبورد آمار لحظه‌ای: کل گردش مالی، کارمزدهای جمع‌آوری شده، نرخ موفقیت تراکنش‌ها.
   - مدیریت تراکنش‌ها با امکان جستجو، تغییر وضعیت (موفق، در انتظار، ناموفق) و حذف.
   - مدیریت کارت‌ها و موجودی حساب‌های کاربری.
   - تنظیمات سامانه: تغییر سقف انتقال روزانه، کارمزد پایه و رمز عبور مدیر.

5. **📖 دفترچه کارت‌ها و مخاطبین (Contacts Book)**:
   - ذخیره کارت‌های پرتکرار با برچسب اختصاصی (مثلاً حقوق، اجاره خانه، شریک تجاری).
   - انتقال وجه سریع با یک کلیک از داخل دفترچه.

6. **🛠️ جعبه ابزار بانکی (Banking Tools)**:
   - تبدیل شماره کارت به شماره شبا (IRAN IBAN Converter).
   - اعتبارسنجی ۱۶ رقم کارت بر اساس الگوریتم رسمی لان (Luhn Algorithm).
   - محاسبه‌گر کارمزد انتقال شتابی.

7. **🎨 سیستم چندحالته لوکس (Dual Royal Themes)**:
   - **دارک مود اشرافی**: ترکیب مشکی آبسیدین، طلایی براق و افکت‌های شیشه‌ای (Glassmorphism).
   - **لایت مود پلاتینیومی**: نقره‌ای درخشان و مرمر لوکس.
   - افکت‌های صوتی کلیک متالیک و زنگ تایید تراکنش (تولید شده با Web Audio API بدون نیاز به فایل خارجی).
   - آتش‌بازی سکه‌ها و جرقه‌های طلایی در زمان موفقیت تراکنش.

## 🚀 راهنمای آپلود روی گیت‌هاب (GitHub)

برای آپلود پروژه در گیت‌هاب، یکی از ۳ روش زیر را می‌توانید انتخاب کنید:

### 🌟 روش اول: آسان‌ترین راه (از طریق مرورگر و بدون نیاز به نصب هیچ برنامه‌ای)
1. وارد سایت [GitHub.com](https://github.com) شوید و به حساب خود لاگین کنید.
2. روی دکمه سبز رنگ **New** یا **Create repository** کلیک کنید.
3. یک نام برای ریپازیتوری انتخاب کنید (مثلاً `royal-card-pay`) و دکمه **Create repository** را بزنید.
4. در صفحه جدید، روی لینک آبی‌رنگ **uploading an existing file** کلیک کنید.
5. تمامی فایل‌ها و پوشه‌های این پروژه (به جز پوشه `node_modules` و `dist`) را با ماوس داخل کادر گیت‌هاب بکشید و رها کنید (Drag & Drop).
6. دکمه سبز رنگ **Commit changes** را بزنید. تمام!

---

### 💻 روش دوم: استفاده از نرم‌افزار رسمی GitHub Desktop
1. نرم‌افزار رایگان [GitHub Desktop](https://desktop.github.com) را دانلود و باز کنید.
2. از منوی File گزینه **Add Local Repository** را انتخاب کنید.
3. مسیر این پوشه (`C:\Users\arab\.gemini\antigravity\scratch\lux-card-transfer`) را انتخاب کنید.
4. روی دکمه **Publish repository** در بالای برنامه کلیک کنید تا پروژه مستقیم به گیت‌هاب شما فرستاده شود!

---

### ⚡ روش سوم: با دستورات خط فرمان Git
اگر نرم‌افزار Git را روی ویندوز نصب کرده‌اید، کافیست ترمینال را در این پوشه باز کرده و دستورات زیر را وارد کنید:
```bash
git init
git add .
git commit -m "Initial commit - Royal Card Pay"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO_NAME.git
git push -u origin main
```
*(به جای USERNAME نام کاربری و به جای REPO_NAME نام ریپازیتوری خود را بگذارید)*

## 🌐 نحوه فعال‌سازی لینک آنلاین رایگان با GitHub Pages
یک فایل آماده در مسیر `.github/workflows/deploy.yml` قرار داده‌ایم که به محض آپلود، سایت را به صورت خودکار آنلاین می‌کند:
1. در ریپازیتوری گیت‌هاب، وارد تب **Settings** شوید.
2. از منوی سمت چپ روی **Pages** کلیک کنید.
3. در بخش **Build and deployment > Source** گزینه **GitHub Actions** را انتخاب کنید.
4. ظرف ۱ دقیقه، لینک سایت شما با آدرس اختصاصی شبیه زیر فعال می‌شود:
   `https://USERNAME.github.io/REPO_NAME/`

## 🏢 راهنمای آپلود روی هاست معمولی (cPanel / DirectAdmin)

این پروژه برای انواع هاست‌های لینوکسی اشتراکی کاملاً بهینه شده است:

1. در ترمینال پروژه دستور ساخت نسخه نهایی را اجرا کنید:
   ```bash
   npm run build
   ```
2. یک پوشه آماده به نام `dist` ساخته می‌شود.
3. وارد پوشه `dist` شوید و تمام فایل‌های داخل آن (فایل `index.html` و پوشه `assets`) را فشرده (Zip) کنید.
4. وارد مدیریت هاست خود (**cPanel** یا **DirectAdmin**) شوید و به **File Manager** بروید.
5. وارد پوشه `public_html` (یا ساب‌دامین مورد نظر) شوید.
6. فایل زیپ را آپلود کرده و روی آن کلیک راست کرده و **Extract** کنید.
7. سایت لوکس شما بلافاصله روی دامنه شما با بالاترین سرعت و بدون نیاز به نصب نودجی‌اس روی سرور در دسترس خواهد بود!
